Convenções para não contar a coisa errada

  • Domínio: n é inteiro. Vetores não vazios usam n≥1 e índices 0 a n−1. A busca binária admite o intervalo vazio, n=0.
  • Contagem: só a operação pedida entra. Testes, retornos, acessos e aritmética dos índices ficam de fora, salvo indicação explícita.
  • Recorrências exatas por divisão: quando indicado, n é potência de 2 ou de 3. Fora disso, pisos e tetos precisam ser considerados.
  • Notação: ⌊x⌋ é o maior inteiro ≤x; ⌈x⌉ é o menor inteiro ≥x. “log” tem base fixa maior que 1; bases são explicitadas quando a conta exata depende delas.
  • C: os exemplos usam inteiros com resultados representáveis. Aritmética de custo constante, sem discutir overflow. A Q5 pede o menor valor.

A / Questão 1

Provar pela definição

5 exercícios · soluções com decisões, contas e conferência

Roteiro de resolução

  1. Reconheça o quantificador

    Em g ∈ ω(f), comece com “seja c > 0 arbitrário”. Você deve construir um limiar m que pode depender de c, mas não de n.

  2. Monte a desigualdade desejada

    Escreva 0 ≤ c·f(n) < g(n). Divida por uma quantidade positiva para isolar uma condição sobre n.

  3. Escolha um limiar seguro

    Se precisa de n > c + 10, use m = ⌈c + 10⌉ + 1. O +1 garante a desigualdade estrita mesmo quando c é inteiro.

  4. Volte à expressão original

    Para todo n ≥ m, justifique a positividade e a desigualdade. Termine citando a definição. Um limite ajuda a descobrir a resposta, mas não substitui a prova solicitada.

ω significa “cresce estritamente mais”, não apenas “é maior para algum n”. Em Θ, você escolhe duas constantes fixas; em ω, deve funcionar para toda constante c > 0.

A prova do exemplo, sem pular a escolha de m#

Exemplo de prova · Q1 · p. 1

Demonstre pela definição que n³ − 10n² ∈ ω(n²). A definição exige: para toda constante c > 0, existe m > 0 tal que 0 ≤ c·n² < n³ − 10n² para todo inteiro n ≥ m.

Preciso de uma pista

Fatore n² e descubra quando n − 10 é maior que c.

Ver resolução detalhada 6 passos

  1. Comece pelo que a definição exige

    Seja c > 0 uma constante arbitrária. Não escolha c = 1: isso provaria apenas uma das infinitas desigualdades exigidas.

  2. Reescreva a função

    n³ − 10n² = n²(n − 10). Para n ≥ 1, n² é positivo; podemos dividir a desigualdade c·n² < n²(n − 10) por n² sem mudar seu sentido.

  3. Isole n

    A desigualdade passa a ser c < n − 10, ou seja, n > c + 10. Agora sabemos qual condição nosso limiar deve garantir.

  4. Escolha um inteiro seguro

    Defina m = ⌈c + 10⌉ + 1. Então m > c + 10 e m ≥ 1. O limiar depende de c, o que é permitido.

  5. Verifique para todos os n do intervalo

    Se n ≥ m, então n − 10 > c > 0. Multiplicando por n² > 0, obtemos 0 ≤ c·n² < n²(n − 10) = n³ − 10n².

  6. Feche a demonstração

    Como a construção funciona para qualquer c > 0 e para todo n ≥ m, a definição de ω está satisfeita. Os valores negativos da função antes de n = 10 não atrapalham: a definição só exige a desigualdade depois do limiar.

Resposta que você precisa conseguir reconstruir

n³ − 10n² ∈ ω(n²), com m = ⌈c + 10⌉ + 1.

Como conferir

Para c = 100, m = 111; em n = 111, n − 10 = 101 > 100. Isso ilustra a escolha, mas a prova é o argumento para c arbitrário.

Erro a evitar

Usar m = c + 10 produz igualdade na fronteira; a definição pede <.

A2 · Treino

Coeficiente na parcela dominante#

Prove pela definição que 3n³ − 7n² ∈ ω(n²), para n inteiro positivo.

Preciso de uma pista

Depois de dividir por n², resolva c < 3n − 7.

Ver resolução detalhada 5 passos

  1. Fixe c arbitrário

    Escreva “seja c > 0”. A meta é obter 0 ≤ c·n² < 3n³ − 7n² para todos os n suficientemente grandes.

  2. Fatore e simplifique

    3n³ − 7n² = n²(3n − 7). Como n² > 0, a desigualdade estrita equivale a c < 3n − 7.

  3. Encontre o limiar

    Somando 7 e dividindo por 3, basta n > (c + 7)/3. Escolha m = ⌈(c + 7)/3⌉ + 1.

  4. Retorne à definição

    Para n ≥ m, 3n − 7 > c > 0. Logo 0 ≤ c·n² < n²(3n − 7) = 3n³ − 7n².

  5. Conclua com os quantificadores

    O argumento vale para todo c > 0 com o m construído. Portanto o pertencimento a ω foi demonstrado.

Resposta que você precisa conseguir reconstruir

3n³ − 7n² ∈ ω(n²); m = ⌈(c + 7)/3⌉ + 1 serve.

Como conferir

A razão (3n³ − 7n²)/n² = 3n − 7 cresce sem limite, coerente com a prova.

Erro a evitar

Não descarte o 3 ao isolar n; ele altera o limiar, embora não altere a classe assintótica.

Minha tentativa e minhas dúvidas
A3 · Treino

Uma prova de o pequeno#

Use a definição para provar n ∈ o(n·log₂ n): para todo c > 0, encontre m tal que 0 ≤ n < c·n·log₂ n para todo inteiro n ≥ m.

Preciso de uma pista

A função à esquerda deve ficar menor que qualquer múltiplo positivo da função à direita.

Ver resolução detalhada 5 passos

  1. Escreva a meta correta

    Seja c > 0 arbitrário. Para o pequeno, queremos n < c·n·log₂ n. Observe que c multiplica a função de referência, e não n sozinho.

  2. Divida por n positivo

    Para n ≥ 1, a condição equivale a 1 < c·log₂ n. Como c > 0, equivale a log₂ n > 1/c.

  3. Elimine o logaritmo

    A função 2ˣ é crescente. Portanto basta n > 2^(1/c).

  4. Escolha m

    Tome m = ⌈2^(1/c)⌉ + 1. Então n ≥ m implica n > 2^(1/c), log₂ n > 1/c e c·log₂ n > 1.

  5. Multiplique de volta e conclua

    Multiplicando por n > 0: 0 ≤ n < c·n·log₂ n. Como isso vale para qualquer c > 0, n ∈ o(n·log₂ n).

Resposta que você precisa conseguir reconstruir

n ∈ o(n·log₂ n), com m = ⌈2^(1/c)⌉ + 1.

Como conferir

Quanto menor c, maior o limiar necessário; isso é esperado e permitido.

Erro a evitar

Não tente escolher um único m independente de c. A definição permite que m varie com c.

A4 · Treino

Quando ω é falso#

A afirmação 5n² + n ∈ ω(n²) é verdadeira? Se for falsa, refute usando a definição.

Preciso de uma pista

Para refutar “para todo c”, basta encontrar um c que impeça qualquer limiar.

Ver resolução detalhada 5 passos

  1. Compare pela razão

    Para n ≥ 1, (5n² + n)/n² = 5 + 1/n. Essa razão se aproxima de 5; não cresce sem limite. Isso sugere que ω é falso.

  2. Escolha um c que derrube a condição

    Escolha c = 6. A definição exigiria 6n² < 5n² + n para todo n a partir de algum m.

  3. Mostre a desigualdade contrária

    Como n ≤ n² para n ≥ 1, temos 5n² + n ≤ 6n². Logo a desigualdade estrita desejada é impossível em qualquer n ≥ 1.

  4. Explique por que não existe m

    Para qualquer m > 0, podemos tomar um inteiro n ≥ max(1,m). Nesse n, a desigualdade continua falsa. Não há limiar que resolva o problema.

  5. Identifique a relação correta

    Também temos 5n² ≤ 5n² + n ≤ 6n² para n ≥ 1. Essas duas cotas mostram que a relação correta é Θ(n²).

Resposta que você precisa conseguir reconstruir

Falsa. c = 6 refuta ω; a função pertence a Θ(n²).

Como conferir

Ser sempre maior que n² não basta para ser ω(n²); um fator constante pode explicar essa diferença.

Erro a evitar

Não use apenas “o grau é igual” quando a questão exigir refutação pela definição.

Minha tentativa e minhas dúvidas
A5 · Treino

Encontrar constantes de Θ#

Prove 4n² − 3n ∈ Θ(n²) encontrando c₁, c₂ e m com 0 ≤ c₁n² ≤ 4n² − 3n ≤ c₂n² para n ≥ m.

Preciso de uma pista

Use n ≤ n² para limitar a parcela negativa por baixo.

Ver resolução detalhada 5 passos

  1. Separe as duas metas

    Precisamos de uma cota inferior positiva e de uma superior. Só mostrar a superior provaria O, não Θ.

  2. Monte a cota superior

    Para n ≥ 1, −3n ≤ 0. Portanto 4n² − 3n ≤ 4n². Podemos escolher c₂ = 4.

  3. Monte a cota inferior

    Como n ≤ n², multiplicar por −3 inverte a desigualdade: −3n ≥ −3n². Somando 4n², obtemos 4n² − 3n ≥ n².

  4. Escolha as constantes juntas

    Use c₁ = 1, c₂ = 4 e m = 1. Para todo n ≥ 1, 0 ≤ n² ≤ 4n² − 3n ≤ 4n².

  5. Escreva a conclusão

    As constantes são fixas e positivas, e a cadeia vale para todo n a partir de m. Logo a função pertence a Θ(n²).

Resposta que você precisa conseguir reconstruir

c₁ = 1, c₂ = 4, m = 1.

Como conferir

Em n = 1, a função vale 1, igual à cota inferior; Θ permite igualdade.

Erro a evitar

Multiplicar uma desigualdade por um número negativo inverte seu sentido.

Fechar recorrências

5 exercícios · soluções com decisões, contas e conferência

Roteiro de resolução

  1. Abra duas ou três vezes

    Substitua T(n/b) pela própria recorrência. Mantenha todos os coeficientes: eles se multiplicam a cada abertura.

  2. Escreva o padrão após k aberturas

    Para T(n)=aT(n/b)+d, o padrão é aᵏT(n/bᵏ)+d·Σ(j=0 até k−1)aʲ.

  3. Pare na base

    Se a base é n=1, imponha n/bᵏ=1; portanto k=log_b n. Neste módulo, n é potência da base indicada.

  4. Substitua o valor da base

    Use T(1), calcule a soma e simplifique. Confira n=1 e o próximo tamanho. Forma fechada exata não é apenas Θ.

Σ(j=0 até k−1)2ʲ = 2ᵏ−1. Há k termos, o último é 2^(k−1). Em recorrências que reduzem n em 1, a parada ocorre após n−1 aberturas.

Fechamento da recorrência do exemplo#

Exemplo de prova · Q2 · p. 1

Encontre a forma fechada de T(1)=1 e T(n)=2T(n/2)+1 para n>1. Considere n=2ᵏ.

Preciso de uma pista

Após duas aberturas, aparece 4T(n/4)+3.

Ver resolução detalhada 6 passos

  1. Faça a primeira substituição

    T(n)=2[2T(n/4)+1]+1 = 4T(n/4)+2+1. O 1 da chamada interna é multiplicado por 2.

  2. Abra mais uma vez

    T(n)=4[2T(n/8)+1]+3 = 8T(n/8)+4+2+1. Os termos adicionados formam uma soma geométrica.

  3. Declare o padrão

    Após k aberturas, T(n)=2ᵏT(n/2ᵏ)+(1+2+⋯+2^(k−1)). A soma é 2ᵏ−1.

  4. Determine a parada

    A base é atingida quando n/2ᵏ=1, isto é, 2ᵏ=n e k=log₂ n. Não pare em n/2ᵏ=0.

  5. Use T(1)

    T(n)=n·T(1)+(n−1)=n·1+n−1=2n−1.

  6. Confira a resposta

    Na base, 2·1−1=1. Para n=2, a recorrência dá 2·1+1=3 e a fórmula dá 3. Para verificar algebricamente, 2[2(n/2)−1]+1=2n−1.

Resposta que você precisa conseguir reconstruir

T(n)=2n−1 para n potência de 2; consequentemente T(n) ∈ Θ(n).

Como conferir

T(4)=7 e T(8)=15. O número de níveis é log₂ n, mas o total de nós cresce linearmente.

Erro a evitar

Responder só Θ(n) não atende a um pedido de equação fechada equivalente.

Mudou o custo local e a base#

Resolva T(1)=2 e T(n)=2T(n/2)+3, com n=2ᵏ.

Preciso de uma pista

Há n folhas de custo 2 e n−1 nós internos de custo 3.

Ver resolução detalhada 5 passos

  1. Abra a recorrência

    T(n)=2[2T(n/4)+3]+3=4T(n/4)+6+3.

  2. Reconheça o padrão

    Após k aberturas: T(n)=2ᵏT(n/2ᵏ)+3(1+2+⋯+2^(k−1)). O fator 3 acompanha toda a soma.

  3. Pare em 1

    Escolha k=log₂ n, de modo que 2ᵏ=n e T(n/2ᵏ)=T(1)=2.

  4. Calcule a soma

    A soma geométrica vale n−1. Logo T(n)=2n+3(n−1).

  5. Simplifique e confira

    T(n)=5n−3. Para n=1, vale 2; para n=2, vale 7, igual a 2T(1)+3.

Resposta que você precisa conseguir reconstruir

T(n)=5n−3.

Como conferir

O coeficiente de n inclui o custo das folhas e o custo dos nós internos.

Erro a evitar

Não reutilize 2n−1 de B1: o valor da base e o custo local foram alterados.

Uma chamada por nível#

Resolva T(1)=4 e T(n)=T(n/2)+2, com n=2ᵏ.

Preciso de uma pista

Sem o fator 2 multiplicando T, os custos locais não dobram.

Ver resolução detalhada 5 passos

  1. Abra duas vezes

    T(n)=T(n/4)+2+2=T(n/4)+4. A cada abertura aparece apenas mais um custo 2.

  2. Escreva o padrão

    Após k aberturas, T(n)=T(n/2ᵏ)+2k. Não existe uma soma de potências de 2, pois há só uma chamada por nível.

  3. Encontre a profundidade

    n/2ᵏ=1 implica k=log₂ n.

  4. Substitua a base

    T(n)=T(1)+2log₂ n=4+2log₂ n.

  5. Verifique

    T(2)=6 e T(4)=8. A fórmula produz esses mesmos valores e T(1)=4.

Resposta que você precisa conseguir reconstruir

T(n)=4+2log₂ n ∈ Θ(log n).

Como conferir

Para n=8, há três reduções: 8→4→2→1; custo 4+3·2=10.

Erro a evitar

Não confunda T(n/2)+2 com 2T(n/2)+1; o primeiro coeficiente conta chamadas.

B4 · Treino

Redução de um elemento#

Resolva T(1)=0 e T(n)=T(n−1)+(n−1) para todo n≥2.

Preciso de uma pista

Escreva o custo até chegar a T(1): (n−1)+(n−2)+⋯+1.

Ver resolução detalhada 5 passos

  1. Abra sem trocar o argumento errado

    T(n−1)=T(n−2)+(n−2). Logo T(n)=T(n−2)+(n−2)+(n−1).

  2. Encontre a parada

    Cada abertura reduz o tamanho em 1. Partindo de n, são n−1 aberturas até chegar a 1.

  3. Liste a soma completa

    T(n)=T(1)+1+2+⋯+(n−1). A parcela 0 da base não adiciona custo.

  4. Use a soma aritmética

    A soma de 1 até r vale r(r+1)/2. Com r=n−1, obtemos (n−1)n/2.

  5. Confira a base e um caso

    Para n=1, a fórmula vale 0. Para n=3, T(3)=T(2)+2=1+2=3, igual a 3·2/2.

Resposta que você precisa conseguir reconstruir

T(n)=n(n−1)/2 ∈ Θ(n²).

Como conferir

Uma cadeia de n chamadas pode custar Θ(n²) se o custo de cada nível cresce com o tamanho.

Erro a evitar

Não responda Θ(n) só porque o tamanho diminui de um em um.

O custo linear reaparece em cada nível#

Resolva T(1)=1 e T(n)=2T(n/2)+n, com n=2ᵏ.

Preciso de uma pista

No nível j existem 2ʲ subproblemas de tamanho n/2ʲ.

Ver resolução detalhada 5 passos

  1. Abra duas vezes

    T(n)=2[2T(n/4)+n/2]+n=4T(n/4)+2n. O custo dos dois filhos é n/2+n/2=n.

  2. Observe o padrão

    int menor = A[0];
    for (int i = 1; i < n; i++) {
        if (A[i] < menor) menor = A[i];
    }
    return menor;
}

int minRec(int A[], int n) { // precondição: n >= 1
    if (n == 1) return A[0];
    int menorAnterior = minRec(A, n-1);
    if (A[n-1] < menorAnterior) return A[n-1];
    return menorAnterior;
}

int minDC(int A[], int ini, int fim) { // intervalo inclusivo, não vazio

    int direita = minDC(A, meio+1, fim);
    if (esquerda < direita) return esquerda;
    return direita;

Em (a) a chamada central custa 1; em (b) os lados têm o mesmo tamanho e o caminho esquerdo custa 2 por nível.

    Um disco executa printf uma vez: H(1)=1. Para n>1, são chamadas de tamanhos n−1,1,n−1.

  2. Recorrência e fechamento de Hanoi

    H(n)=2H(n−1)+1. Após n−1 aberturas, H(n)=2^(n−1)H(1)+2^(n−1)−1=2ⁿ−1.

  3. Base da busca

    Para n=0, o retorno ocorre antes dos testes de valores: C(0)=0.

  4. Use a restrição de tamanhos

    Quando n=2ᵏ−1, cada lado tem (n−1)/2=2^(k−1)−1. Ir à direita custa 1 comparação; ir à esquerda custa 2; ambos deixam o mesmo tamanho. Portanto o pior caso satisfaz C(n)=2+C((n−1)/2).

    Uma chave menor que todos os valores percorre o ramo esquerdo até o vazio. Há k nós não vazios, custo 2k=2log₂(n+1).

Transferir os três padrões para soma#

Escreva três funções C que somem um vetor não vazio: soma(A,n), somaRec(A,n) reduzindo n em 1 e somaDC(A,ini,fim) dividindo o intervalo inclusivo ao meio. Conte apenas adições de valores do vetor ou de somas parciais; desconsidere aritmética de índices e suponha que os resultados caibam em int.

Preciso de uma pista

A estrutura do mínimo funciona; troque a combinação por uma soma.

Ver resolução detalhada 6 passos

  1. Defina a base e a unidade

    Para um elemento, a soma é esse elemento. Nenhuma adição de valores é necessária para simplesmente retorná-lo. Incrementos e cálculo de meio não entram na contagem.

  2. Versão iterativa

    Inicialize total=A[0]. Some A[i] para i=1,…,n−1. Após cada iteração, total contém a soma do prefixo já processado.

  3. Recursão por n−1

    Se n==1, retorne A[0]. Guarde somaRec(A,n−1) e retorne esse resultado mais A[n−1]. O elemento final completa a soma do vetor.

  4. Divisão e conquista

    Se ini==fim, retorne A[ini]. Some os retornos de [ini,meio] e [meio+1,fim]. Como as partes são disjuntas e cobrem todo o intervalo, nenhum elemento é omitido ou contado duas vezes.

  5. Conte as adições

    Iterativa: n−1. Recursiva: C(1)=0, C(n)=C(n−1)+1=n−1. Divisão e conquista: C(1)=0 e C(n)=C(⌈n/2⌉)+C(⌊n/2⌋)+1=n−1.

  6. Rastreie um exemplo

    Para [5,−2,4], a soma é 7. No DC de [0,2], a esquerda [0,1] soma 3; a direita [2,2] devolve 4; a raiz soma 3+4=7. São duas adições, iguais a n−1.

Implementação completa

int soma(int A[], int n) { // n >= 1
    int total = A[0];
    for (int i=1; i<n; i++) total = total + A[i];
    return total;
}

int somaRec(int A[], int n) { // n >= 1
    if (n==1) return A[0];
    int anterior = somaRec(A,n-1);
    return anterior + A[n-1];
}

int somaDC(int A[], int ini, int fim) { // intervalo inclusivo não vazio
    if (ini==fim) return A[ini];
    int meio = ini + (fim-ini)/2;
    int esquerda = somaDC(A,ini,meio);
    int direita = somaDC(A,meio+1,fim);
    return esquerda + direita;
}
Resposta que você precisa conseguir reconstruir

As três implementações fazem n−1 adições de valores com as inicializações mostradas.

Como conferir

Se você inicializou total=0 e somou desde i=0, também pode estar correto, mas essa versão faz n adições. A contagem deve corresponder ao seu código.

Erro a evitar

Não retorne o menor dos resultados por copiar o algoritmo anterior; agora a combinação é uma adição.
